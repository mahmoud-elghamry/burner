# Burner PetroBaker — LCP-01

PLC control panel for a gas scrubber and two burners (Riello RS100, DLX 53 SHFP) heating two oil
tanks on a natural-gas field. Siemens S7-1200 (CPU 1214C) programmed in TIA Portal V15.1, KTP400 HMI.
