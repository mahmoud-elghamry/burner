# 0010 — وضوح البرنامج والشاشة بالإنجليزي

- **الحالة:** accepted للنطاق أدناه · 2026-11-10 حسب تاريخ الجلسة الحالي.
- **المصدر:** المستخدم طلب تطبيق مراجعة الوضوح بالإنجليزي، ويحدد لاحقًا المواضع التي يريدها بالعربي.
- **السياق:** الحصر السابق في `docs/مراجعة الوضوح.md` مؤرخ 11-11 كما أُنشئ؛ لا نعيد تأريخه. تعليقات 135 شبكة و74 تاج HMI كانت فارغة.

## النطاق

1. عنوان وظيفي قصير وشرح إنجليزي لكل شبكة، مع المراجع الكاملة في آخر التعليق. `C0x` يتوسع إلى مرجعَي C07 وC08 بدل أن يتصدر العنوان.
2. تعليقات إنجليزية لجميع أعضاء واجهات FB وDB والمؤقتات وIO، وتعليقات تاجات HMI ووحداتها ومعانيها.
3. نصوص إنجليزية واضحة للادر والعرض، مع **Info الإنذارات بالعربي البسيط** حسب توجيه المستخدم اللاحق في نفس الجلسة؛ تمييز فرق الحرارة عن حدها، وسماح START عن RUN، وذاكرة السبب عن الدخل الحالي، وأمر الصمام عن إثبات موضعه.
4. إعادة تسمية الأعضاء الملتبسة التالية فقط في هذه الجولة؛ الأسماء الواضحة وأسماء الأجهزة والـpins والتاجات العامة على HMI تبقى ثابتة. تتحدث أهداف HMI الرمزية إلى أسماء أعضاء PLC الجديدة دون إضافة طبقة نقل.

| البلوك | القديم | الجديد |
|---|---|---|
| Burner | TOn | AutoRestartTemp |
| Burner | TStg | SecondStageOnTemp |
| Burner | TStgOff | SecondStageOffTemp |
| Burner | Tmax | ControlTemp |
| Burner | Enabled | StartEnabled |

| Burner | TcSlow | InvalidTempTimerDone |
| Burner | Ready | ReadyToStart |

| Scrubber | ValvesNormal | ValveCommandsNormal |

## ثوابت المراجعة

تبقى واجهتا Main ‏10/2 و4/3، وأرقام البلوكات والشاشات والإنذارات وبتاتها وعناوين IO وترتيب الشبكات والأنواع والقيم والأزمنة والـRetain كما هي. تحسين نص الإعدادات لا يحول ms إلى ثوانٍ، ولا يضيف زر تشغيل أو حسابًا أو وظيفة حماية جديدة. الـPLC يطلب التسخين والمرحلة فقط؛ أمان اللهب داخل علبة البيرنر.

## توجيه الشاشة اللاحق: عرض مشغّل بسيط

المستخدم نقل أن شاشة التشغيل معقدة وتحتاج مهندسًا، وطلب رسومات بسيطة ولمبات: الحساس السليم أخضر، والمشكلة أحمر أو أصفر حسب الحالة؛ أمر الخرج ON أخضر وOFF رمادي. يُطبّق هذا على Overview وصفحتَي البيرنر وصفحة السكرابر مع إبقاء الصفحات الست والربط. تعرض رسمة تانك بسيطة وتعريف الأجهزة والحرارة ولمبات المدخلات والأوامر، دون مقياس مستوى مستمر غير موجود في الحساسات.

تفاصيل أرقام الحالات والحدود المحسوبة وFirstOut لا تزاحم عرض التشغيل اليومي؛ الإنذارات في صفحتها وشرحها بالعربي، والإعدادات في صفحتها. تظل الأسباب والتشخيصات في PLC والتاجات الموجودة، ولا نضيف ماركرات عرض أو DB موازيًا. لمبة الصمام تصف أمر ملفه، وليست إثبات وضع الصمام.
