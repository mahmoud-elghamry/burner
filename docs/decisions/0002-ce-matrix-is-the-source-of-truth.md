# 0002 — الـ C&E هو المرجع، وبيتولّد من سكريبت

- **الحالة:** accepted · 2026-10-26
- **السياق:** العميل طالب Cause & Effect Matrix قبل التنفيذ. في مشروع الأوناش اتعلّمنا إن
  الكود من غير مرجع مكتوب بيخلّي كل مراجعة تبتدي من الصفر.

## القرار

1. `deliverables/PH-LCP-01-CE_Rev*.xlsx` **بيتولّد** من `tools/build_ce.py`. التعديل بيتعمل
   في السكريبت، وبعدين `py tools\build_ce.py`. **محدّش يعدّل الـ xlsx بإيده.**
2. كل صف ليه رقم ثابت (`C03`، `C07b` …) ومصدر (`Client` أو `PH proposal`).
3. **كل network في الكود بيتكتب في الـ comment بتاعه رقم الصف** اللي بينفّذه. وكل صف
   ليه اختبار PLCSIM بنفس الرقم.
4. أي سلوك محتاجه الكود ومش في الـ C&E: يتضاف كصف `PH proposal` الأول.

## اللي اترفض

- **Excel بيتعدّل بإيده:** بيتلخبط بين النسخ، ومينفعش نعمل diff في git.
- **نكتب الكود الأول ونطلّع منه الـ C&E:** العميل لازم يوافق قبل التنفيذ مش بعده.
