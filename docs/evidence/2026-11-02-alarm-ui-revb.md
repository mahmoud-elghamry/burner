## نقاط التشغيل اللي اتراجعت

- إنذارات أسباب تريب الـscrubber سجلات ماسكة؛ مش دليل إن السبب لسه موجود. الصمامات بتتوصف كأوامر لأن مفيش feedback.
- `PSH` بيطلب فلير مفتوح وساكشن مقفول، ومش بيغيّر تحكم الدرين ولا طلبات البيرنرات. `LSHH` بيطلب الساكشن مقفول، ومش بيعمل تريب للفلير، والدرين بيتبع أي إشارة مستوى عالي.
- إنذار `LSH` فوري مع الدخل؛ أمر الدرين متأخر بالأرقام المتظبطة، افتراضيًا 3 ثواني فتح و5 ثواني قفل بعد زوال إشارتَي المستوى العالي. الدرين NC، وممنوع مع E-STOP ماسك أو مهلة درين ماسكة، لكنه ممكن يشتغل قبل RESET الـscrubber بعد رجوع الكهربا.
- مهلة الدرين: افحص الطلب الطويل قبل `S2`؛ المسح مش محتاج الحساسات ترجع سليمة، وممكن يعيد أمر الفتح فورًا لو الطلب موجود.
- رفض الأرقام: القيمة القديمة رجعت بالفعل؛ بالنسبة للإنذار ده RESET بيمسح البيان بس. نفس `S2` مش زرار منفصل عن باقي مسارات المسح.
- مسح الـscrubber ممكن يرجّع أوامر الصمامات. مسح أعطال البيرنر محتاج زوال أسباب العطل و`RUN=0`، وبعده START جديد؛ lockout يتعالج ويتعمله reset محلي عند علبة البيرنر قبل `S2` ثم START. مفيش remote reset متنفّذ مفترض من `F49`.
- low level: اختفاء الإنذار مش وعد بإعادة التشغيل. AUTO يرجع بس لو سماح START لسه موجود وفيه طلب حرارة والحمايات سليمة؛ MAN محتاج START جديد بعد انقطاع الدورة.
- RUN بدون طلب: الصياغة بتقول إن الإشارة فضلت موجودة 30 ثانية والطلبات مفصولة؛ مش بتقول إن البيرنر وقف فعليًا.

- `HMI_ALARMS` وعنوان network المسح وشيت C&E صف `C04b` بيقولوا «الحساسين يتفقوا». اللادر فعليًا بيسمح بـ `ResetPulse AND (NOT LSH OR LSHH)`، يعني غياب حالة `LSHH` عالي من غير `LSH` عالي. مستوى بين الحساسين كفاية للمسح رغم اختلاف الإشارتين. اتصحح وصف §1 و§5 والنص المعروض؛ ملفات PLC والـC&E ماتغيّروش.
- C&E صف `C04` بيختصر القفل في رجوع `LSH`؛ اللادر بيطلب غياب إشارتَي المستوى العالي طول تأخير القفل. النص المعروض ماشي على شرط اللادر الكامل.
- القاعدة القديمة في `AGENTS.md` بتقول drain NO؛ التنفيذ الحالي والـC&E و`F50` بيقولوا NC. اتّبعنا التنفيذ الحالي حسب طلب المستخدم وRev B.
- ملاحظات C&E `C07a`/`C08a` لسه بتقول HMI warning؛ تصنيف الشاشة الحالي Fault حسب Rev B، من غير تغيير شرط التشغيل أو مصدره.
