# تجربة البانل فقط — ورقة تجهيز وعرض

**الغرض:** تجربة المداخل والبرنامج ولمبات الشاشة وريلايات الخروج، من غير بيرنرات أو صمامات موصلة. هذه خطوات متوقعة من النسخة الحالية، وليست نتائج اختبار منفذ. يبدأ العرض بوضع سليم، ثم نغير مدخلًا واحدًا ونراقب النتيجة.

## 1. قبل البريدجات

1. فني اللوحة يفصل ويؤمّن تغذية/توصيلات البيرنرات والصمامات الخارجية؛ تفضل تغذية PLC والشاشة ودوائر اختبار اللوحة المناسبة فقط. نراقب LED الخرج وملف الريلاي ولمبات الباب؛ لا نحقن أي جهد في المخارج أو دوائر البيرنر.
2. راجع تسميات الأطراف الفعلية مع الرسم قبل التوصيل. الأرقام أدناه من الرسم V1، صفحات 10–13. الفني يجهز بريدجات/مفاتيح اختبار معزولة والطاقة مفصولة؛ تشغيلها لاحقًا يحاكي كونتاكت الجهاز الغائب. تستخدم أزرار الباب والسلكتور الموجودة نفسها، ولا تعمل بريدج دائم على STOP أو E-STOP.
3. تأكد من نسخة البرنامج **المحمّلة** على PLC ونسخة الشاشة، وليس اسم المشروع المفتوح فقط. المرجع الحالي `D:/tasks/burner/tia/Burner/Burner.ap15_1`؛ مقارنة الأونلاين لم تُنفذ في إعداد هذه الورقة. المحاكاة الجديدة ما زالت مؤجلة، ولا تعني الورقة أنها نجحت.
4. لا توجد Overrides أو Force فعالة. لو فيه Force، يتراجع مع الفني قبل العرض. لا نعدل الكود أو نعطل حماية لتصفير إنذار.

**في الجدول:** `1` = الدخل ظاهر ON على PLC، و`0` = OFF. بريدج XI أو XI2 يغلق **زوج الأطراف المذكور فقط** لمحاكاة الكونتاكت. أرقام الأزواج ليست تعليمات لتوصيلها بـ0V. قنوات X5 للحرارة مختلفة تمامًا: لا يدخلها 24V.

**الحرارة بأقل تجهيز:** حساس Type K واحد في TE-501، وشورت مستقل لكل من القنوات الثلاث الأخرى. لا تضع الشورت بالتوازي مع الحساس المتغير لأنه سيلغي قراءته. إذا لم يتوفر حساس، يمكن بدء عرض التشغيل والتريبات بالقراءات الثابتة فقط، وتأجيل عرض فصل الحرارة المتغيرة.

**شرط شورت الحرارة:** القناة مفعلة Thermocouple/Type K/Celsius وInternal reference؛ سيقرأ الشورت تقريبًا حرارة الكارت، وليس صفرًا مضمونًا ولا حرارة تانك حقيقية. هذا موثق من Siemens، وإعداد Internal reference مسجل للمشروع سابقًا لكنه يُراجع في النسخة المحمّلة. تأكد أن القراءات الأربع مستقرة وسليمة وأقل من حد تشغيل المرحلة الثانية قبل START. لو ظهرت `----` أو `32767` أو حرارة غير معقولة، أصلح الإشارة/الإعداد قبل استكمال العرض. لا تشترك القنوات في حساس واحد أو بريدج يجمع بينها.

**Spare لا يحتاج بريدجات:** I0.7 وI12.5 وI12.6 وI12.7، وقنوات TC من IW104 إلى IW110 المعطلة. لا يوجد حساس LSL للسكرابر في النسخة الحالية.

## 3. أول تشغيل — اتبع الترتيب ده

1. شغّل البانل وراجع حالات الجدول على PLC وقراءات الشاشة. اضغط STOP للأول والثاني ثم اتركهما؛ RUN وLOCKOUT للاتنين يفضلوا `0`.
2. الأرقام التالية أمثلة على القيم الافتراضية؛ راجع **القيم المقبولة** الفعلية قبل العرض: SP=70°C، HYST=5°C، STG=10°C، TStart=120s، فتح الدرين بعد 3s، غلقه بعد 5s، أقصى فتح 600s. إن احتجت تعديلًا، بعد STOP للبيرنرين فقط، ثم تحقق من قبول القيم. لا تغيّرها أثناء السماح بالتشغيل.
3. انتظر استقرار قراءات TC وانتهاء مهلة بدء الكارت، ثم اضغط RESET واتركه. لو الدرين كان عنده طلب سابق، انتظر زمن غلقه. الطبيعي الآن: `Q0.2=1` و`Q0.3=0` و`Q0.4=1`؛ مخارج البيرنرين ولمبات مراحلهما كلها `0`.
4. اضغط START الأول S1 واتركه. مع حرارة أقل من 60°C والقيم أعلاه: `Q0.0=1`، و`Q0.1=0` لحد وصول RUN.
5. اقفل مفتاح محاكاة RUN الأول XI:7–8 بعد ظهور الطلب وقبل TStart. يصبح `Q0.1=1`؛ H1 وH2 ينوروا لو التسليك سليم.
6. اضغط START الثاني S6 واتركه: `Q0.5=1` و`Q0.7=1`، ثم اقفل RUN الثاني XI:25–26: `Q0.6=1` و`Q1.0=1` مع الحرارة الأقل من 60°C.

**هذه هي حالة «الكل شغال» التي نبدأ منها كل اختبار مستقل.** RUN هنا إشارة نحاكيها يدويًا، وليس دليل تشغيل بيرنر فعلي. كل مرة طلب الحرارة يقع بسبب STOP أو حرارة أو تريب، افتح RUN الخاص به سريعًا خلال أقل من 30 ثانية؛ بقاؤه ON سيولد إنذار RUN without request.

## 4. غيّر مدخلًا واحدًا وراقب

ارجع إلى «الكل شغال» قبل كل صف مستقل. لا تنتقل من عطل إلى عطل وتترك أسبابًا قديمة. `RESET ثم START` يعني: السبب زال والحرارة سليمة وRUN=0، ثم RESET واتركه، ثم START جديد، ثم حاكي RUN بعد ظهور الطلب. لو طلب الحرارة وقع بسبب عطل، فالمرحلة الثانية ولمباته تفصل أيضًا.

| الاختبار | تعمل إيه؟ | الخرج المتوقع | ترجع إزاي؟ |
|---|---|---|---|
| ضغط PSH-101 | افتح XI:1–2 | البيرنران يفصلان؛ `Q0.2=0` و`Q0.4=0`؛ الدرين لا يتغير بسبب الضغط وحده | افتح RUN للاتنين، رجّع بريدج الضغط، RESET ثم START لكل بيرنر؛ رجوع البريدج وحده لا يكفي |
| مستوى LSH-102 | افتح XI:3–4 فقط | بعد TDrnOn: `Q0.3=1`؛ البيرنران والفلير والساكشن يستمرون | اقفل البريدج؛ بعد TDrnOff يصبح `Q0.3=0`، بدون RESET |
| مستوى LSHH-103 | افتح LSH أولًا ثم LSHH، XI:3–4 ثم XI:5–6؛ ده ترتيب ارتفاع المستوى الطبيعي | البيرنران يفصلان، `Q0.4=0`، `Q0.2` يظل `1`؛ الدرين `Q0.3=1` بعد TDrnOn من أول مستوى عالٍ | افتح RUN للاتنين؛ رجع LSHH ثم LSH، انتظر غلق الدرين؛ RESET ثم START لكل بيرنر |

| AUTO/MAN الثاني S5 | غيّر السلكتور | نفس السلوك للثاني فقط | افتح RUN الثاني؛ START جديد بعد اختيار الوضع المطلوب |
| وقود BR02 | اقفل مفتاح XI2:1–2 لمحاكاة تغيّر الوقود | BR02 يفصل؛ BR01 لا يتغير | افتح RUN الثاني؛ ارجع لوضع الغاز المطلوب ثم START جديد. هذه تجربة إشارة فقط، دون تشغيل وقود |
| E-STOP S0 | اضغط زر الطوارئ الحقيقي | مخارج التشغيل التسعة كلها `0`؛ ريلايات الخروج تفصل | افتح RUN للاتنين، حرر الطوارئ، RESET ثم START لكل بيرنر |

**RESET S2:** جرّبه مرة والسبب ما زال موجودًا: لا يجب أن يتجاوز الحماية. جرّبه بعد زوال السبب وRUN=0: يمسح العطل القابل للمسح ولا يشغّل بيرنرًا كان FAULT من نفسه. زر RESET ليس أمر START. رفع الضغط وحده أو عطل بيرنر واحد لا يُفتح الدرين بسببه.

## 5. الحرارة — بحساس واحد

مع SP=70 وHYST=5 وSTG=10، خلي القناة الثانية للتانك ثابتة وسليمة وأقل من 60°C. الحرارة المستخدمة هي **الأعلى** بين قناتَي التانك؛ راقب رقم الشاشة، لا تقدّرها بلمس الحساس. استخدم مصدر تسخين آمن ومناسب للحساس، مثل حمام ماء مضبوط، دون لهب مكشوف.

| الخطوة على TE-501 | BR01 المتوقع |
|---|---|
| أقل من 60، START ثم RUN | `Q0.0=1` و`Q0.1=1` |
| ارفع الحرارة إلى 62 أو أكثر وهي طالعة | المرحلة الثانية `Q0.1=0`، وطلب الحرارة `Q0.0=1`؛ عند 60 بالضبط لا يشترط فصل المرحلة |
| ارفع إلى 70 أو أكثر | `Q0.0=0` و`Q0.1=0`؛ افتح RUN فور سقوط الطلب |
| برّد إلى 68 | يفضل متوقفًا في AUTO |
| برّد إلى 65 أو أقل | في AUTO يرجع طلب الحرارة؛ حاكي RUN بعد ظهور الطلب. المرحلة الثانية ترجع فقط لما الأعلى من القراءتين ينزل **أقل من 60** |
| افصل حساس TE-501، أو أزل شورت اختبار قناة بديلة | ترك القناة مفتوحة: بعد تشخيص الكارت يختفي الرقم الطبيعي ويمسك عطل حرارة، وBR01 يفصل. **تركيب شورت سليم ليس عطلًا يُكتشف بالضرورة** |

في اختبار القطع: افتح RUN، أعد إشارة القناة وتأكد أنها سليمة، ثم RESET ثم START. كرر اختبار القطع مستقلًا على TE-502: نفس مخارج BR01. وعلى TE-503 ثم TE-504: مخارج BR02 هي التي تفصل. انقل الحساس المتغير للثاني فقط بعد STOP للاتنين وفصل الطاقة أثناء إعادة التجهيز، مع إعادة شورت مستقل للقناة التي تركها؛ كرر حدود الحرارة باستخدام `Q0.5/Q0.6` ولمبتي `Q0.7/Q1.0`.

## 6. اختبارات إضافية بعد العرض الأساسي

- **START بلا RUN:** من الحالة السليمة والبيرنر متوقف، اضغط START واترك RUN=0. الطلب يستمر حتى TStart ثم يفصل بعطل RUN not received in time؛ بعدها RESET ثم START. الافتراضي 120s وليس فشلًا فوريًا.
- **RUN قبل START:** البيرنر متوقف، اقفل RUN أولًا. لا يبدأ طلب الحرارة؛ وبعد 30s دون طلب يظهر RUN without request. افتح RUN، RESET ثم START. كرر للأول والثاني.
- **MAN:** اختر MAN ثم START ثم RUN. الوصول إلى SP يوقفه؛ افتح RUN. التبريد لا يعيد الطلب حتى START جديد.
- **STOP مع START مضغوط:** STOP يفوز. ترك STOP مع إبقاء START مضغوطًا لا يعيد التشغيل؛ حرر START ثم اضغطه من جديد.
- **مهلة الدرين:** LSH فقط مفتوح، ومن أول ظهور `Q0.3=1` انتظر TDrnMax. الافتراضي 600s؛ يقفل الدرين ويظهر إنذار. أزل السبب ثم RESET. الضغط على RESET مع بقاء المستوى عاليًا قد يعيد فتحه؛ لذلك رجّع السبب أولًا.
- **الإعدادات:** اضغط STOP للاتنين وافتح RUN؛ التعديل الصحيح يتقبل، وخارج المدى يرفضه PLC. بعد START لأحدهما يُرفض أي تغيير قيمة. عدم وجود طلب حرارة وحده لا يثبت STOP؛ قد يكون AUTO منتظرًا. اختبار PLC خارج المدى قد يحتاج كتابة مراقبة لأن حقل HMI يمنع الإدخال أصلًا.
- **قطع ورجوع الكهرباء:** STOP للاتنين وافتح RUN أولًا. افصل تغذية البانل ثم أعدها؛ لا يبدأ البيرنران تلقائيًا، والسكرابر ينتظر RESET. اختبارات restart أثناء التشغيل والـ24 ساعة تبقى في سجل تحقق مستقل.

Q1.1 احتياطي. الرسم V1 يصف الدرين NO وبعض المخارج Spare؛ المرجع الحالي هنا هو قرارات المستخدم وتوصيف الكود: الدرين NC، وH5/H6 مستخدمتان. عنوان Q لا يثبت أن الصمام تحرك فعليًا.

سجل لكل اختبار: **المدخل قبل/بعد، LED الدخل، المخارج الفعلية، الشاشة، PASS/FAIL**. لو ظهر إنذار غير متوقع، توقف عن إضافة تغييرات وسجل نصه/ID وهل هو نشط أو تاريخي، وقراءات TC الأربع، وحالات RUN/LOCKOUT. كل لمبات الحساسات خضراء لا تعني أن ذاكرة العطل مُسحت؛ تحقق من شروط RESET. صفحة Alarms وعرض Info ما زالا عملًا متبقيًا؛ وجود تعريفات الإنذارات وحده لا يثبت ظهورها. لا تعتبر فشل عرض الإنذار دليلًا على غياب العطل في PLC.

بعد العرض: STOP للاتنين، RUN=0، وفصل الطاقة ثم إزالة بريدجات الاختبار واستعادة التسليك بمعرفة الفني. لا تترك أي بريدج اختبار قبل توصيل معدات الموقع.
