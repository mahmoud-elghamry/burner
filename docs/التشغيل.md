# وصف التشغيل

**تأكيد المستخدم 2026-10-27:** MAX، وMAN دورة واحدة، وSTART بعد رجوع الكهرباء، واستمرار طلب البيرنرات عند تريب scrubber مؤكدة مباشرة.
القرار الأخير مسجل أيضًا يوم 26 أكتوبر؛ المصدر: `docs/evidence/2026-10-27-user-operating-rules-confirmed.md`. لا يُعاد طلب تأكيد هذه الأربع.

**ده المرجع اللي الكود بيتبني عليه، وهو اللي بيتراجع.** الـ C&E
(`deliverables/PH-LCP-01-CE_RevA.xlsx`) فيه التريبات والإنذارات بس، والملف ده فيه كل الباقي:
الأوضاع، والزراير، والـ RESET، وإيه اللي بيحصل بعد ما الكهربا ترجع.

**الأرقام اللي جنب كل حاجة** (`C07b`، `S-03` …) هي نفس الأرقام اللي هتلاقيها على الـ network في
TIA، وعلى الاختبار في PLCSIM. لو حاجة مكتوبة هنا ومالهاش network، يبقى فيه نقص. ولو فيه network
مالوش سطر هنا، يبقى زيادة.

## 0 · الصورة الكبيرة

اللوحة فيها **3 أجزاء منفصلين**، وكل جزء ليه أوامره وتريباته:

| الجزء | بيعمل إيه |
|---|---|
| **الـ scrubber** | بينضّف الغاز الداخل للبيرنرات. 3 حساسات و3 صمامات |
| **BR01** (Riello RS100) | بيسخّن التانك `TK01` |
| **BR02** (DLX 53، بتاع العميل) | بيسخّن التانك `TK02` |

**تريب الـ scrubber مش بيقفل البيرنرات**، وتريب بيرنر مش بيأثّر على التاني. **الـ E-STOP بس هو
اللي بيقفل الكل.**

**والـ PLC مش بيولّع حاجة.** كل بيرنر جواه علبة كنترول بتعمل الـ purge والشرارة ومراقبة اللهب
وبتفتح الغاز. الـ PLC بيقول للبيرنر **"اشتغل"** و**"على العالي"**، وبيقرا منه **"أنا شغال"**
و**"أنا عطلان"**. بس كده. (`decisions/0001`)

## 1 · الـ scrubber

### الصمامات ليها وضعين بس

| | `XV-401` فلير | `XV-402` درين | `XV-403` ساكشن | المخارج |
|---|---|---|---|---|
| **طبيعي** | مقفول | مقفول | **مفتوح** | الـ 3 مخارج شغالين (`Q0.2` و`Q0.3` و`Q0.4`) |
| **تريب** | **مفتوح** | **مفتوح** | مقفول | الـ 3 مخارج مفصولين |

**ليه التريب = كله مفصول؟** الفلير والدرين **NO** (من غير كهربا بيفتحوا)، والساكشن **NC** (من
غير كهربا بيقفل). يعني لو الـ PLC وقف أو الـ 24V قطعت، الصمامات بتروح للوضع الآمن **لوحدها**.

### إمتى بيدخل تريب، وإمتى بيرجع

| | |
|---|---|
| **يدخل تريب** | `PSH-101` (ضغط عالي) أو `LSHH-103` (مستوى عالي جدًا) أو E-STOP، **أو أول ما اللوحة تشتغل** |
| **يرجع طبيعي** | لما حد يدوس **`RESET`** والسبب يكون راح. **مش بيرجع لوحده أبدًا** |
| **إنذار بس** | `LSH-102` (مستوى عالي). بيطلع على الشاشة، والصمامات مش بتتحرّك |

**`S-01` · ليه بيبدأ في تريب لما اللوحة تشتغل؟** عشان محدّش يتفاجئ إن الساكشن فتح لوحده بعد
رجوع الكهربا. **حد لازم يبص ويدوس RESET.** (قرار `F10`. لو مش موافق، قولّي)

## 2 · البيرنر (BR01 وBR02 نفس الكلام بالظبط)

### البيرنر دايمًا في حالة من دول

| الحالة | يعني | المخارج |
|---|---|---|
| **متوقف** `IDLE` | مش مطلوب، أو مستني الحرارة تنزل | مفصولة |
| **بيبدأ** `STARTING` | الـ PLC طلب، والبيرنر بيعمل purge وبيولّع. **حوالي دقيقة** | طلب الحرارة شغال |
| **شغال** `RUNNING` | البيرنر قال "أنا شغال"، يعني صمامات الغاز فتحت | طلب الحرارة شغال، والمرحلة التانية حسب الحرارة |
| **عطل** `FAULT` | فيه مشكلة. **مش بيطلع منه غير بـ `RESET`** | مفصولة، والإنذار على الشاشة |

### `B-01` · الزراير والأوضاع

كل بيرنر ليه على الباب 3 حاجات: **AUTO/MAN** و**START** و**STOP**.

| الزرار | بيعمل إيه |
|---|---|
| **START** | **"البيرنر ده مسموحله يشتغل."** من غيره البيرنر مش هيشتغل في أي وضع |
| **STOP** | **"اقفل وماتشتغلش تاني"** لحد ما حد يدوس START. شغال في الوضعين |
| **AUTO** | بعد START، الـ PLC بيشغّل ويقفل **لوحده** حسب الحرارة (الجزء الجاي)، **طول اليوم** |
| **MAN** | START بيشغّله **مرة واحدة**. لما يوصل الـ setpoint (70) بيقفل، **ومش بيرجع يشتغل لوحده.** محتاج START تاني. ولو اتقفل لأي سبب تاني (المستوى مثلًا)، برضه محتاج START (R-03) |

**في الوضعين، كل الحمايات شغالة**، يعني المستوى والثيرموكابل والعطل والـ E-STOP. والمرحلة التانية
بتشتغل بنفس القاعدة في الوضعين.

**تغيير AUTO ↔ MAN والبيرنر شغال:** البيرنر يقفل، ومحتاج START جديد (R-02).

**التسليك:** `S1`/`S6` (START) زراير **NO**، يعني بتدّي 1 لما تتضغط. **و`S3`/`S7` (STOP) زراير
**NC**، يعني بتدّي **1 وهي سايبة و0 لما تتضغط**، وكمان لو السلك اتقطع، فالسلك المقطوع = STOP.
`S3` مكتوب NC في رسم الـ legend (صفحة 2). **`S7` يتأكد إنه NC زيه** (`F20`).

**`B-02` · بعد الكهربا ما ترجع، أو بعد الـ RESET، أو بعد الـ E-STOP:** **محدّش بيشتغل لوحده.**
لازم حد يدوس START لكل بيرنر. (قرار `F14`. مع الغاز، محدّش يتفاجئ ببيرنر ولّع)

### `C07b` / `C07c` · الحرارة (في AUTO)

الحرارة اللي بيتحسب بيها = **الأعلى** بين الثيرموكابلين اللي على التانك (الداخل والخارج).

```
 درجة الحرارة     البيرنر
 ────────────     ──────────────────────────────
    ≥ 70          يقفل                          C07b
   65 – 70        لو كان شغال: يكمّل على الواطي
                  لو كان مقفول: يفضل مقفول       (ده الـ 5 درجات hysteresis)
    ≤ 65          يرجع يشتغل
   60 – 65        على الواطي (المرحلة الأولى)
    < 60          على العالي (المرحلة التانية)   C07c
                  ويرجع للواطي عند 62، مش 60: فرق درجتين عشان الريليه ماتقلبش (F41، 2026-10-28)
```

الأرقام (70 و5 و10) بتتغيّر من الشاشة. (`decisions/0003`)

### شروط التشغيل

البيرنر مش هيشتغل، **ولو كان شغال هيقفل**، لو:

| الشرط | الرقم | يرجع إزاي |
|---|---|---|
| مستوى التانك تحت `LSL` | `C07a` | **لوحده** لما المستوى يرجع (في AUTO) |
| الحرارة وصلت 70 | `C07b` | **لوحده** عند 65 (في AUTO) |
| BR01 شغال بقاله 24 ساعة متواصلة | `C07h` | **لوحده** في الطلب الجاي. ده مطلوب في كتالوج RS100 |

### الأعطال (تدخل `FAULT`، ومحتاجة `RESET`)

| العطل | الرقم | معناه |
|---|---|---|
| ثيرموكابل مقطوع أو قراءته غلط، **أي واحد من الاتنين** | `C07d` | من غير القراءتين مينفعش نثق في الحرارة (`F15`) |
| البيرنر عمل lockout | `C07e` | اللهب طفى أو مولّعش. **علبة البيرنر قفلت الغاز خلاص.** والريسيت الأول على البيرنر نفسه، وبعدين `RESET` في اللوحة |
| البيرنر مولّعش خلال دقيقتين | `C07f` | طلبنا منه، ومردّش بـ "أنا شغال" |
| البيرنر وقف لوحده وهو شغال | `C07g` | مثلًا ترموستات الأمان `TS` فصل، أو ضغط الغاز قل. **من غير الصف ده، الـ PLC كان هيفضل يطلب من بيرنر واقف** |

### اللمبات

| اللمبة | بتنوّر إمتى |
|---|---|
| `H1` / `H5` (1st stage) | الـ PLC طالب من البيرنر يشتغل (`Q0.0` / `Q0.5`) |
| `H2` / `H6` (2nd stage) | الـ PLC طالب المرحلة التانية (`Q0.1` / `Q0.6`) |
| `H3` / `H4` (FAULT) | البيرنر في lockout. **متسلّكة على البيرنر مباشرة، والـ PLC مالوش دعوة بيها** |

**مهم:** `H1` و`H2` بتقول **"طلبنا"**، مش **"البيرنر ولّع"**. إذا كان شغال فعلًا ولا لأ، بتشوفه
على الشاشة. `H1`/`H2` بيشغّلهم `R1`/`R2` بالتسليك، و`H5`/`H6` بيشغّلهم الـ PLC من `Q0.7`/`Q1.0`
بنفس المعنى (`F13`).

## 3 · الـ E-STOP (`C01`)

| بيحصل إيه | بإيه |
|---|---|
| البيرنرين يفصلوا | **بالسلك** (`S0` بيقطع كهربا البيرنرين)، **والـ PLC كمان** بيشيل الأوامر |
| الـ scrubber يدخل تريب | الـ PLC |
| بعد ما تفكّه | `RESET` للـ scrubber، و`START` لكل بيرنر |

## 4 · الـ RESET (`S2`)

**بيمسح أي عطل سببه راح.** لو السبب لسه موجود (الثيرموكابل لسه مقطوع مثلًا)، العطل بيفضل.
**الـ RESET مش بيشغّل بيرنر.** بيرجّعه لـ "متوقف"، ومحتاج START بعدها.

## 5 · الشاشة (KTP400)

**عرض بس، ومنها بتتغيّر الأرقام** (70، و5، و10، ووقت البدء). **مفيش START أو STOP من الشاشة**،
عشان يبقى فيه مكان واحد للأوامر، وهو الباب. (قرار، لو عايز غير كده قولّي)

## 6 · السيناريوهات، وإزاي تتأكد من كل واحد

كل سيناريو بيتجرّب على PLCSIM: **تغيّر الدخل من watch table، وتشوف المخرج.** النتيجة بتتسجّل في
`docs/evidence/`. **ده إزاي تتأكد إن الكود صح من غير ما تقرا ولا network.**

| # | الموقف | المفروض يحصل | إزاي تختبره |
|---|---|---|---|
| 1 | **يوم عادي:** التانك مليان، والحرارة 40، وAUTO، وSTART | `STARTING`، ثم RUN يوصل، ثم `RUNNING` على العالي. عند 60 يبقى على الواطي، وعند 70 يقفل، وعند 65 يرجع | `LSL`=1، والثيرموكابلين=400، و`S4`=1، واضغط `S1`. اعمل `RR`=1. غيّر الاتنين لـ 600 ثم 700 ثم 650 |
| 2 | **التانك فضي** والبيرنر شغال | يقفل، ولما المستوى يرجع يشتغل لوحده | `LSL`=0 ثم 1 |
| 3 | **اللهب طفى** | `FAULT` وإنذار، ومفيش تشغيل لحد RESET | `Rflt`=1، ثم 0، ثم `S2` |
| 4 | **مولّعش** | بعد دقيقتين: `FAULT` | START، وسيب `RR`=0 |
| 5 | **وقف لوحده** | `FAULT` | وهو `RUNNING`، خلي `RR`=0 و`Rflt`=0 |
| 6 | **ثيرموكابل بايظ** | `FAULT` | جرّب 3 مرات على قناة واحدة بس: `32767` (قطع سلك)، و`−32768`، و`2500` (250°C بره المدى). والتانية سليمة |
| 6ب | **STOP والـ START مضغوطين مع بعض، أو START محشور** | يقف، ومايشتغلش | `S3`=0 و`S1`=1 مع بعض. وبعدين خلي `S1`=1 دايمًا واعمل STOP وRUN للـ PLC |
| 7 | **ضغط الـ scrubber عالي** | فلير ودرين يفتحوا، والساكشن يقفل، **والبيرنرات تكمّل** | `PSH`=0، وبُص على `Q0.2` لـ `Q0.4` وعلى البيرنر |
| 8 | **E-STOP** | كله يقف. بعد RESET الـ scrubber يرجع، **والبيرنرات لأ** لحد START | `S0`=0، ثم 1، ثم `S2` |
| 9 | **الكهربا قطعت ورجعت** | الـ scrubber في تريب، والبيرنرات متوقفة | PLCSIM: STOP ثم RUN |
| 10 | **MAN** | يشتغل بـ START، ويقفل عند 70، **ومايرجعش** عند 65 | `S4`=0، ثم `S1`، و`TE` لـ 700 ثم 650 |

**ده اللي محتاج تتأكد منه في الموقع (PLCSIM مش بيعرفه):** إن الحساسات متسلّكة fail-safe (افصل
السلك فيطلع تريب)، وإن الكارت بيدّي 32767 لما سلك الثيرموكابل يتقطع، وإن البيرنر الحقيقي بيولّع
في أقل من دقيقتين.

## 8 · قواعد دقيقة للكود (من مراجعة Codex، 2026-10-27)

دي المواقف اللي كانت هتخلّي اللي بيكتب الكود يخمّن. **كل سطر هنا بيبقى network عليه رقمه.**

| # | الموقف | القاعدة |
|---|---|---|
| R-01 | الـ START والبيرنر مش جاهز (المستوى واطي أو فيه عطل) | **بيترفض.** وفي AUTO، لو الحرارة عالية بس (فوق 65)، START بيتقبل، والبيرنر بيستنى الحرارة تنزل |
| R-02 | تغيير AUTO ↔ MAN والبيرنر شغال أو بيبدأ | يقفل، والسماح بيتلغي، ومحتاج START جديد |
| R-03 | MAN واتقفل لأي سبب (المستوى، أو STOP، أو وصل 70) | خلاص، الدورة خلصت، ومحتاج START |
| R-04 | AUTO والمستوى وقع ورجع | يرجع **لو** الحرارة لسه محتاجة (تحت 65، أو كان شغال والحرارة تحت 70) |
| R-05 | زرار START | بيتقبل على **الحافة** بس، وبعد ما اتشاف مسيوب. زرار محشور أو مضغوط وقت رجوع الكهربا مش بيشغّل حاجة. **ولو STOP وSTART مع بعض، STOP بيكسب** |
| R-06 | زرار RESET | على **الحافة** بس. مسكه ضاغط مش بيعمل حاجة زيادة. ولو السبب لسه موجود، العطل بيفضل |
| R-07 | RESET والبيرنر التاني شغال سليم | **مش بيلمسه.** بيمسح الأعطال اللي سببها راح بس. وكل بيرنر اتمسح عطله محتاج START لوحده |
| R-08 | إيقاف الـ 24 ساعة | يشيل الطلب، ويتأكد إن RUN وقع، و**60 ثانية OFF على الأقل**، وبعدين يبدأ تاني. ولو RUN مارضيش يقع خلال 30 ثانية: عطل |
| R-09 | RUN شغال **قبل** ما نطلب، أو فضل شغال **بعد** ما قفلنا بـ 30 ثانية | عطل "RUN غلط". والبيرنر مش بيبدأ لو RUN شغال أصلًا. **و`C0xg` (وقف لوحده) مش بيتحسب لو إحنا اللي قفلنا** |
| R-10 | بعد رجوع الكهربا، الكارت بيدّي `32767` لثواني وهو بيعمل calibration | الحرارة ممنوعة لحد ما القناتين يبقوا سليمين. ولو فضلوا بايظين أكتر من 10 ثواني: عطل `C0xd` |
| R-11 | تغيير الأرقام من الشاشة | الـ PLC بيرفض أي رقم بره المدى (جدول Parameters) ويطلع إنذار، والقديم بيفضل. واللي **بيقلّل** الحرارة يطبّق فورًا، واللي **بيزوّدها** يستنى لحد ما البيرنر يقف. ونفس الكلام بعد رجوع الكهربا: لو الأرقام المحفوظة بايظة، الافتراضي بيرجع |
| R-12 | BR02 اتغيّر لديزل وهو شغال | **مش متعرّف من الكتالوج.** لحد ما يتأكد: لو `Rfuel2` اتغيّر والبيرنر شغال، يقفل ومحتاج START (`F25`) |
