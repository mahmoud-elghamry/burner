# اختبار BR01 (RS100) في الورشة

اللوحة `LCP-01` متسلّكة، وفيها الـ PLC الحقيقي، وثيرموكابل على تانك. البيرنر على **غاز مباشر، من غير الـ
scrubber**. والشاشة `KTP400` غالبًا لسه ماوصلتش.
**الاختبار مراحل، وقبل كل مرحلة فيه قرار.** نقدر نقف بعد أي مرحلة، والنتيجة مكتوبة.
المراحل 1 و2 و3 من غير غاز. المرحلة 4 فيها ولعة حقيقية، ولها شروطها.

**من غير scrubber:** البرنامج مش بيربط البيرنر بالـ scrubber (`C03`/`C05`: البيرنرات بتكمّل)، فالبيرنر بيشتغل عادي.
بس مداخل `PSH-101` و`LSH-102` و`LSHH-103` (`I0.0`…`I0.2`) لو فاضية، الـ PLC بيقراها تريب، فالإنذارات بتفضل
ظاهرة، ومخرج الدرين `Q0.3` بيفتح ويقفل بعد 10 دقايق. **وصّلهم بـ 24V** (jumper على أطراف اللوحة: `XI:1` مع `XI:2`، و`XI:3` مع `XI:4`، و`XI:5` مع `XI:6`)
عشان الـ scrubber يبقى "سليم". دول حساسات الـ scrubber، مش حساسات البيرنر.

**من غير شاشة:** كل حاجة بتتشاف من TIA أونلاين في watch table. وكل الأرقام ليها قيمة افتراضية جوه الـ PLC
(`SP` = 70، و`HYST` = 5، و`STG` = 10)، فالبرنامج مش محتاج الشاشة عشان يشتغل. حط في الـ watch table:

| التاج | يعني |
|---|---|
| `"BR01_DB".State` | `0` واقف، و`1` بيولّع، و`2` شغال، و`3` عطل |
| `"BR01_DB".Tmax` | الحرارة بعُشر الدرجة (`400` = 40.0 °C) |
| `"BR01_DB".F_EStop` و`F_TC` و`F_Lockout` و`F_NoStart` و`F_RunLost` و`F_RunWrong` | العطل اللي حصل |
| `"BR01_DB".HeatReq` و`Stage2` | الـ PLC طالب `TL` و`TR` |
| `"Par".SP` و`"Par".HYST` | تقدر تغيّرهم من هنا (Modify)، بعُشر الدرجة |

**الحدود:** الـ PLC بيدّي `TL` و`TR` بس، وبيقرا `RUN` و`LOCKOUT`. الـ purge والولعة والتحكم في اللهب شغل علبة
`RMG88`. **ممنوع أي jumper على حساس جوه البيرنر** (ضغط الغاز، وضغط الهوا، وإشارة اللهب). (`decisions/0001`)

**أوقف فورًا بالـ E-STOP واقفل محبس الغاز اليدوي** في أي حالة من دول: ريحة غاز، أو لهب في وقت مش متوقع، أو
صمام بيفتح ويقفل ورا بعض، أو حاجة سخنت أو طلّعت دخان.

## 1 · اللوحة من غير البيرنر

**الوضع:** بريكر كهربا البيرنر **مفصول**، فالـ `TL` و`TR` بيوصلوا للريلاي بس. ده بيتأكد من التسليك والبرنامج قبل
ما أي حاجة تتحرك.

| # | الخطوة | المفروض يحصل | النتيجة |
|---|---|---|---|
| 1.1 | كهربا اللوحة، وتنزيل البرنامج على الـ CPU الحقيقي، وRUN | الـ watch table بيقرا من الـ PLC، والـ scrubber في تريب (`S-01`). ولو الشاشة موجودة، بتقرا هي كمان | |
| 1.2 | `RESET` (`S2`) | الـ scrubber بيرجع طبيعي (`Q0.2` و`Q0.4` = `1`، و`Q0.3` = `0`)، و`"BR01_DB".State` = `0` | |
| 1.3 | كل دخل من الجهاز نفسه: `S0` و`S1` و`S2` و`S3` و`S4`، و`LSL-TK01` (`TS` مش داخل على الـ PLC، وبيتجرّب في 2.3) | الدخل بيتغيّر في الـ watch table (`I0.4` و`I0.6` و`I1.0` و`I1.1` و`I1.2` و`I12.1`) | |
| 1.4 | `S3` STOP: سايبه، وبعدين مضغوط | سايبه = `1`، ومضغوط = `0` (NC، `F20`) | |
| 1.5 | AUTO، والتانك مليان، والحرارة أقل من `SP`، و`START` | ريلاي `R1` بيشتغل (`Q0.0`) ولمبة `H1` بتنوّر. بعد 120 ث من غير `RUN`: `FAULT` (`C07f`) | |
| 1.6 | `RESET` وبعده `START`، والحرارة أقل من 60 | `R1` وبعده `R2` (`Q0.1`) ولمبة `H2`، **بس** بعد ما `RUN` يوصل. من غير `RUN`، `R2` مش بيشتغل | |

**الثيرموكابل**

| # | الخطوة | المفروض يحصل | النتيجة |
|---|---|---|---|
| 1.7 | قارن قراية `TE-501` و`TE-502` بترمومتر مرجعي | الفرق أقل من ±2.2 °C (دقة type K) | |
| 1.8 | سخّن الحساس (مية سخنة أو بإيدك) | الرقم بيعلى، **مش بينزل** (لو نزل، القطبية معكوسة) | |
| 1.9 | افصل سلك حساس واحد بس | الكارت بيدّي `32767`، والبيرنر بيروح `FAULT` (`C07d`). **سجّل الرقم اللي ظهر** | |
| 1.10 | رجّع السلك، وبعدين `RESET` و`START` | يشتغل تاني | |

**قرار:** كل اللي فوق تمام؟ ساعتها نوصّل كهربا البيرنر.

## 2 · البيرنر متوصّل، والغاز مقفول

**الوضع:** محبس الغاز مقفول، فحساس ضغط الغاز الأدنى مفتوح. الكتالوج بيقول إن البيرنر في الحالة دي
**مش بيبدأ خالص**: المروحة مش بتلف، ومفيش lockout، واللمبة مش بتنوّر (RS100 §6.8.1، وجدول الأعطال ص34).
**مفيش غاز بيخرج في المرحلة دي.**

| # | الخطوة | المفروض يحصل | النتيجة |
|---|---|---|---|
| 2.1 | `START` | `TL` بيقفل عند البيرنر (طرف X1 `2–3`)، والبيرنر واقف. **سجّل: المروحة لفّت ولا لأ؟** | |
| 2.2 | استنى 120 ث | `FAULT` بسبب "مولّعش" (`C07f`)، و`TL` بيفتح | |
| 2.3 | `TS` افتحه وبعدين `START` | البيرنر مش بياخد كهربا. الـ PLC مش بيعرف بـ `TS`، فبيطلع نفس العطل `C07f` | |
| 2.4 | `E-STOP` و`TL` مقفول | كهربا البيرنر بتتقطع بالسلك (`NC2`)، والـ PLC بيشيل `TL` (`C01`)، والـ watch table بيقول E-STOP | |
| 2.5 | فك الـ E-STOP | **مفيش حاجة بتشتغل لوحدها.** `RESET` وبعدين `START` | |

**الـ lockout من غير غاز:** من غير غاز، البيرنر **مش هيعمل lockout** (2.1). عشان نختبر الـ PLC، **نعمل إشارة
الـ lockout على طرف الـ PLC**، مش جوه البيرنر:

| # | الخطوة | المفروض يحصل | النتيجة |
|---|---|---|---|
| 2.6 | اعمل `Rflt` (`I0.5`) = `1` من طرف اللوحة، والبيرنر شغال على `START` | `TL` بيفتح على طول، و`FAULT` (`C07e`). `F_Lockout` = `1` | |
| 2.7 | شيل الإشارة، واعمل `START` من غير `RESET` | مرفوض. `RESET` وبعدين `START` بيشغّله | |
| 2.8 | سلك `Rflt` مفصول والبيرنر شغال | **سجّل اللي يحصل.** دلوقتي مش هيحصل حاجة، لأن الـ lockout = `1` (`F46`، لسه مفتوح) | |

**قرار:** هنكمّل للولعة النهارده؟ لو لأ، نقف هنا ونكتب النتايج.

## 3 · قبل الولعة: ضبط البيرنر (شغل فني RS100، مش الـ PLC)

دي مش اختبارات PLC. البيرنر لازم يتظبط الأول على الكتالوج (§6): ضغط الغاز، وكامات الهوا للمرحلة الأولى والتانية،
وحساس الهوا، وحساس الغاز الأدنى، وتحليل الاحتراق. **الفني هو اللي يقرر يظبطه إزاي**، وممكن يحتاج يدّي `TL` و`TR`
من عنده.

| البند | تمام؟ |
|---|---|
| خط الغاز متجرّب ضد التسريب | |
| ضغط الغاز داخل البيرنر في المدى | |
| البيرنر اتظبط واشتغل مع الفني | |

**قرار:** الفني موافق نشغّله من اللوحة؟

## 4 · ولعة حقيقية من اللوحة

**تحذير من الكتالوج:** لو البيرنر عمل lockout، **ماتعملوش reset أكتر من مرتين ورا بعض.** في التالتة اقفل الغاز
واسأل الفني.

| # | الخطوة | المفروض يحصل | النتيجة |
|---|---|---|---|
| 4.1 | محبس الغاز مفتوح، وAUTO، و`START` | purge لمدة حوالي 25 ث، وبعدين ولعة عند حوالي 43 ث. `RUN` بيوصل، والـ watch table بيقول `RUNNING`. **سجّل الوقت من `START` لـ `RUN`** (لازم يبقى أقل من 120 ث) | |
| 4.2 | الحرارة أقل من 60 | `TR` بيقفل، والبيرنر بيروح المرحلة التانية (السيرفو بيلف) | |
| 4.3 | `STOP` (`S3`) | البيرنر بيقف، ومش بيشتغل تاني غير بـ `START` | |
| 4.4 | `START`، وبعدين E-STOP واللهب شغال | البيرنر بيقف على طول بالسلك، والـ PLC بيشيل `TL` | |
| 4.5 | واللهب شغال، اقفل محبس الغاز اليدوي | البيرنر بيعمل lockout في أقل من ثانية (§6.8.3)، والـ PLC بيطلع `FAULT`. **سجّل العطل اللي ظهر:** `C07e` (lockout) ولا `C07g` (وقف لوحده). ده بيجاوب `F42` | |
| 4.6 | بعد 4.5: اقفل كهربا البيرنر 10 ث وبعدين رجّعها | **اللمبة الحمرا لسه منوّرة؟** (المتوقع أيوه: lockout ثابت، `F49`) | |
| 4.7 | reset عند البيرنر، وبعدين `RESET` و`START` من اللوحة | يشتغل تاني | |
| 4.8 | `"Par".SP` من الـ watch table = حرارة التانك + 2 °C (أقل رقم `400` = 40.0)، و`"Par".HYST` = `30`. البيرنر لازم يكون واقف (STOP) وانت بتعلّي `SP`، وبعدين `START` (`D6`) | بيقف عند `SP`، وبيرجع يولّع عند `SP − 3`. ولو التانك بيسخن ببطء، **حرّك الحساس لمية سخنة** | |
| 4.9 | البيرنر شغال، واقطع كهربا اللوحة 10 ث | البيرنر بيقف. لما الكهربا ترجع، مش بيولّع لوحده لحد `START` (`S-01`) | |
| 4.10 | رجّع `"Par".SP` = `700` و`"Par".HYST` = `50` | | |

**مش بيتختبر هنا:** إيقاف الـ 24 ساعة (`C07h`)، لأنه محتاج يوم كامل.
